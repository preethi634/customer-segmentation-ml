# Customer Segmentation Using K-Means Clustering

## Project Overview

This project applies unsupervised machine learning to segment mall customers based on age, annual income, and spending score.

## Objectives

* Explore customer demographic and spending patterns.
* Standardize features for clustering.
* Apply K-Means clustering to identify customer segments.
* Visualize clusters to understand customer behavior.

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Matplotlib and Seaborn
* Google Colab

## Methodology

1. Data exploration and preprocessing
2. Feature standardization using StandardScaler
3. Elbow Method to explore the number of clusters
4. K-Means clustering with four clusters
5. Cluster visualization and interpretation

## Key Findings

Identified four customer segments with different age, income, and spending characteristics. These segments can help inform customer-targeted marketing strategies.
